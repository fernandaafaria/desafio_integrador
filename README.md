*Sistema de Benefícios*

Sistema desenvolvido em Java durante o curso de Desenvolvimento de Sistemas – Jovem Aprendiz Metrô, no SENAI.
O programa coleta informações do funcionário e verifica, por meio de regras condicionais, quais benefícios ele pode receber.

**Tecnologias**
- Java
- IntelliJ IDEA

**Conteúdos praticados**
- Variáveis e tipos de dados
- Entrada de dados com Scanner
- Estruturas condicionais
- Operadores lógicos
- Variáveis booleanas
- Operador ternário
- Manipulação de Strings
